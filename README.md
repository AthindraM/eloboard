# EloBoard
A Discord bot made using Python to show a leaderboard of you and your friends' ranks in your competitive games

## Games Supported
- League of Legends
    - Solo/Duo Queue
    - Flex
- Teamfight Tactics

## How to Use:
1. Create a profile using `/create_profile`
    - this profile is linked to your Discord profile, so one profile per person
2. Link your account(s) using `/link_accounts` and your in-game name (game_name#tagline)
    - you can link as many accounts as you want
    - Teamfight Tactics account is the same as League of Legends
3. Check your profile using `/profile`
4. Use `/leaderboard` to see where you rank amongst your friends!
